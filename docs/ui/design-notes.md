# Design notes

Ideas and principles about how Day Log should look, feel and perform. Not commitments: when
one becomes work, it gets a Linear issue (linked here). Add to this freely.

## Principles

### The knuckle test
The best Apple Watch apps can be used with one knuckle. Day Log should be that simple. **If
it's hard to use, it won't get used**, and then the data doesn't matter. Every interaction
should pass: one key or one tap, no thinking. (This is part of why an agentic shape is on the
table later: say or press one thing, and it figures out the rest. See the product-shape spike.)

### Beauty is a feature
The pill already looks good: the round capsule, the colors, the glow. Push it further. It runs
locally, so there's no excuse for anything less than buttery: **target a solid 60 Hz** (120 Hz
on ProMotion screens) for every open, close, morph, and glow change, the way Wispr Flow's bar
feels.

### Colors should be research-backed
Today's colors (pearl → yellow → orange → red for focus) are intuition. Map them to what's
actually known about color and attention, arousal and focus, then decide. See the color
research spike.

## Process
v1 is about getting the shape out. Then use it daily, refine from real use, and eventually
hand it to a few other people for feedback.
